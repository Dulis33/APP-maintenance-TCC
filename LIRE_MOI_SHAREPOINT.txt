PACK SHAREPOINT PROPRE - SANS PWA

Ce pack ne contient PAS :
- sw.js
- manifest.json
- manifest.webmanifest
- service worker

Utilisation conseillée sur PC :
1) Dézipper le dossier complet.
2) Mettre le dossier dans SharePoint / OneDrive synchronisé.
3) Ouvrir le dossier depuis l'explorateur Windows, pas depuis l'aperçu web SharePoint.
4) Double-cliquer sur ouvrir_app_pc.bat ou index.html.

Si l'appli ne s'ouvre pas :
- ouvrir test_chemins.html : tous les fichiers doivent afficher ✅.
- ouvrir nettoyage_cache_pwa.html une fois, cliquer sur Nettoyer, puis réessayer index.html.

Ne pas remettre dans ce dossier : sw.js, manifest.json, manifest.webmanifest.
